Framework

From separate answers to a structured decision.

Users choose their decision models and declare how the business operates. DecisionFlow compiles that description into an inference-ready decision structure, then evaluates the complete decision jointly.

01
Score locally

Bring the model you trust.

Use hosted APIs, open-weight checkpoints, Python callables, HTTP endpoints, or cached probabilities. DecisionFlow does not import or lock you to a model provider.

Get started

Add structure without replacing your model.

Install the core package, provide model probabilities or configure a scorer adapter, then declare the relationships your application already knows.

Browse the repository ↗ Constraint format ↗
Python
# Install the exact SDD backend
pip install -e '.[sdd]'

from decisionflow import DecisionFlow

request = {
    "state": {"channel": "card"},
    "questions": [
        {"id": "route", "type": "choice",
         "options": ["billing", "security"]},
        {"id": "fraud", "type": "noul"},
    ],
    "probabilities": {
        "route": {"billing": .6, "security": .4},
        "fraud": .7,
    },
}

constraints = {"hard": [{"expr": {"implies": [
    {"eq": [{"var": "fraud"}, True]},
    {"eq": [{"var": "route"}, "security"]}
]}]}]}

result = DecisionFlow(backend="auto").infer(
    request, constraints
)
print(result.joint_map)
print(result.marginals)
print(result.valid_mass)
